## About The Project
This is a mobile app created as my final submission for the capstone project in the Meta's React Native specialization on Coursera. It was created with React Native using Expo. It also serves as a portfolio piece on my GitHub profile.

**It includes:**
- Navigation using react-navigation
- State management using the Zustand library
- Unit and component tests using Jest and RNTL (react-native-testing-library)
- E2E tests using Maestro
- Data persistence with SQLite and AsyncStorage
- Wireframes for the UI created with Figma

## Getting started
### 1. Make sure you have the required software installed on your computer
Before attempting the following steps, make sure that you have installed git, npm and node on your device.
### 2. Download and clone this repository to your local machine
Use the "git clone" command for this. The link to use with this command can be found on this project's repo on GitHub.
### 3. Install all the required dependencies
Navigate to the project's folder in a Terminal (for Linux and MacOS) or a Powershell app (for Windows). Or, you may alternatively, open the project folder with VSCode and use a compatible command line interface from there. Once you do that, type the following command into the command line: "npm install" -- this will install all the required dependencies.
### 4. Start the metro server
Once you're done with the previous step, type the following command into the command line: "npm start" and press enter. Then wait until the Metro server starts up. You will then need to open the Expo Go app on your mobile device (this app was tested on an Android phone). If you don't have Expo Go app yet, go to your app store and install it. 
### 5. Use the Expo Go app
Inside the Expo Go app, select the "Scan QR code" option and scan the QR code that was displayed in the command line / terminal. Keep in mind, that you will need to be connected to your home Wi-Fi network in order for this to work. Then, after some time, the app will start.
